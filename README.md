# 📸 Portfólio de Fotografia Gastronômica & Food Styling

> 🚀 **Projeto 100% criado via "Vibe Coding" utilizando o Claude Code.**

Este repositório contém uma página web de portfólio para um food stylist e fotógrafo de comida. O grande diferencial deste projeto é a sua forma de criação: nenhuma linha de código foi escrita manualmente. Toda a estrutura, estilo e interatividade foram gerados por Inteligência Artificial. Neste projeto, o **Claude Code** atuou como o desenvolvedor executivo, enquanto a direção de arte, as ideias e os *prompts* ditaram o resultado final.

## 🍽️ Sobre o Projeto

O portfólio foi construído em um **arquivo HTML único** (`index.html`), contendo todo o CSS e JavaScript de forma *inline*.

### ✨ Funcionalidades
* **Single-Page Application:** Estrutura simples e direta em uma única página.
* **Design Responsivo:** Adaptável para dispositivos móveis, tablets e desktops (gerado pela IA).
* **Galeria de Imagens:** Seção dedicada para exibir os trabalhos de food styling.
* **Zero Dependências:** Sem necessidade de instalar pacotes ou rodar servidores complexos.


## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estrutura)
* **CSS3** (Estilização inline)
* **JavaScript** (Interatividade inline)
* **Claude Code / Anthropic** (Geração de Código)
